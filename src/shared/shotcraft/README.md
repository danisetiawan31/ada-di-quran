# 🎬 Shotcraft Integration for Remotion

Folder ini disediakan untuk menampung komponen, helper, dan resep motion design dari **video-shotcraft**.

## 📌 Cara Menggunakan Resep Shotcraft di Video Anda

Skill `video-shotcraft` sudah terpasang secara global di:
`~/.gemini/config/skills/video-shotcraft`

### Kategori Resep Tersedia:
1. **`camera/`**: 2.5D perspective tilt, smooth pan, dolly zoom, orbit.
2. **`typography/`**: Kinetic text, word highlight, stamp drop, typewriter.
3. **`ui-entrance/`**: Card deck fly-in, bento grid reveal, cascade tiles.
4. **`transition/`**: Whip pan, split-screen wipe, dynamic zoom cuts.
5. **`interaction/`**: Realistic cursor movement, click pulse, typing simulation.

### Contoh Pemakaian:
Untuk memakai resep di video baru (misal `src/videos/02-promo/`):
Cukup minta ke agent:
> *"Buatkan video promo di src/videos/02-promo dengan efek 2.5D camera tilt dan kinetic typography dari Shotcraft."*
Agent akan langsung mengimpor resep yang sesuai ke dalam scene Anda.
